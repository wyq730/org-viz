# 组织图谱 · Org Atlas

本地运行的通用树图查看器。将 CSV 转成节点 JSON，拖入页面即可探索一个或多个树。无需后端、构建、CDN 或网络连接。

## 开始使用

1. 双击根目录 `index.html`，在浏览器中打开。
2. 点击“试用演示数据”，或将 JSON 文件拖入窗口，也可点击“导入 JSON”。
3. 搜索姓名、展开节点、缩放或点击节点查看详情。

已为当前数据生成 `dr_org_data/org_export_20261120/org_export_nodes_2026-11-20.json`（1335 个节点，2 棵树），可以直接拖入。它包含原 CSV 配置指定的手机号与邮箱，仅在本地保存和使用。页面不请求网络、不保存文件到 localStorage，关闭/刷新页面后需要重新导入。

## CSV → JSON

需要 Python 3.9+，无第三方依赖。从项目根目录运行：

```sh
python3 scripts/csv_to_json.py \
  dr_org_data/org_export_20261120/org_export_employees_2026-11-20.csv \
  dr_org_data/org_export_20261120/org_export_nodes_2026-11-20.json \
  --id-column open_id \
  --parent-id-column 上级open_id \
  --config configs/employees.json
```

适配其他 CSV，只需修改 ID 列参数和配置文件：

```json
{
  "name_column": "姓名",
  "abstract": [
    {"columns": ["性别", "工作城市"], "separator": ", "},
    {"columns": ["部门完整路径"]}
  ],
  "other_info": {"直属上级": "直属上级", "入职": "入职日期", "邮箱": "邮箱", "手机号": "手机号"}
}
```

- `abstract` 每个配置生成一行，可合并多列，空值跳过；默认分隔符为 `, `。
- `other_info` 定义详情标签与 CSV 列的映射，删除配置项即可不输出该字段。
- CSV 按 UTF-8（兼容 BOM）读取，所有 ID 保持字符串，保留工号前导零。ID 和 parent 去除首尾空白。
- 列缺失、列数不匹配、空/重复 ID、循环关系或空数据会报错并以非零状态退出。校验通过后才原子替换输出文件。
- 文件中找不到的父 ID 保留，并统计数量；查看器会将相关节点当作独立子树。

## 节点协议

JSON 顶层为数组，每个节点格式如下：

```json
[
  {
    "node": "001",
    "name": "示例姓名",
    "parent": "",
    "abstract": ["上海 · 产品", "示例团队"],
    "other_info": {"入职": "2026-01-01", "邮箱": "demo@example.com"}
  }
]
```

`node` 是唯一且非空的字符串，`name`、`parent` 是字符串，空 parent 表示根。`abstract` 为字符串数组，`other_info` 为对象；这两个展示字段缺省时使用空数组/对象。详情对象中的非字符串值按文本展示。缺失父节点可导入，重复 ID 或环会拒绝导入，先前有效视图不会被覆盖。

## 交互

- **初始视图**：展开前三层，先以清晰可读的比例对准第一棵树的根；大树可以缩小或点击“适应视图”看全局。
- **展开/收起**：卡片右下角同时显示直属下级人数和全部下级总人数，全部下级包含所有层级的后代，不含当前节点，折叠不改变统计。点击该按钮展开/收起，保持该节点在屏幕上的位置。收起后再次展开会保留更深层展开状态。
- **全部展开/全部折叠**：底部工具栏可展开所有树的全部层级，或折叠为仅显示各棵树的根节点；操作后自动适应视图。全部折叠后仍可搜索任意节点，定位时重新展开其祖先路径。
- **缩放**：`＋ / −` 或滚轮，以鼠标位置为缩放中心。触控板的缩放手势如产生 wheel 事件也可使用。点击百分比恢复 100%；“适应视图”适配所有已展开节点，不改变展开状态。
- **平移**：拖动画布空白区域，触屏可单指拖动空白区域。触屏缩放使用 `＋ / −` 按钮。
- **搜索**：点击顶部搜索框，或按 `⌘K / Ctrl+K`；按姓名部分匹配，忽略大小写。结果显示摘要和 ID，区分同名节点。↑/↓ 选择，Enter 定位，Escape 关闭列表。
- **定位**：选择结果后，展开目标的祖先路径，居中、高亮并调整到可阅读的比例；不收起其他分支。清空搜索移除高亮，保留视图和展开状态。
- **详情**：点击卡片，或聚焦节点后按 Enter/空格，在点击处显示完整摘要和详情。点击外部、关闭按钮或 Escape 关闭；弹窗自动限制在视口内。
- **重新导入**：拖入新文件或点击顶部“导入 JSON”；校验失败时保留原数据。

全部展开后，千人树的全局缩略图文字会很小；通过缩放查看局部，或搜索直接定位。当前不含导出图片、筛选或持久化功能。

## 文件结构

- `scripts/csv_to_json.py`：通用 CSV 转换器。
- `configs/employees.json`：当前员工 CSV 的展示映射。
- `index.html`、`web/`：离线页面、样式和交互。
- `examples/demo.json`：虚构的多树样例；首屏演示按钮内置同一份样例，不需要 fetch 本地文件。
- `tests/`：转换器与浏览器验证。
- `dr_org_data/`：已有飞书采集工具及数据。
- `dev_logs/2026-11_dev_org_viz.md`：方案与开发记录。
